# Changelog

## 0.2.0 — 2026-11-19

- Add a footer theme switch (light/dark); Enterprise host settings now use a distinct sliders icon.
- Make the sidebar handle draggable vertically and across the screen to dock on either side.
- Allow renaming saved repositories without changing their identity.
- Add collapsible folders for grouping saved repositories.
- Show the favorite button on more repository headers and pages, including layouts without header markers.

## 0.1.1 — 2026-11-19

- Document architecture, Enterprise onboarding, security, testing, and release workflows with selected mdxcn-compatible Markdown figures.
- Add the project-local mdxcn skill and a pull request documentation template. Extension runtime behavior is unchanged.

## 0.1.0 — 2026-11-19

- Add local repository favorites for GitHub.com and user-approved GitHub Enterprise Server hosts.
- Add integrated sidebar with search, reorder, docking, resizing, pinning, and adaptive themes.
- Add Manifest V3 build, automated unit/browser tests, documentation, and packaged output.
- Add a separate Firefox MV3 build with a background script and an unsigned XPI for temporary installation.
